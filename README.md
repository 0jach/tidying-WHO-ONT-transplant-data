# Organ Donation and Transplantation Data Tidying

This repository contains work based on the **Global Observatory on Donation and Transplantation** dataset, produced through collaboration between the **World Health Organization (WHO)** and the **Spanish National Transplant Organization (ONT)**. According to the project description, the data can be downloaded from the observatory export database for the years **2000–2024**, and the related questionnaire is also publicly available.

The dataset is a large international collection of information on organ donation and transplantation activity, including variables on deceased and living donors, transplant activity, and waiting-list related measures.

The main conceptual reference for this work is Hadley Wickham’s article **“Tidy Data”**, which defines tidy datasets through three main principles:

- each variable forms a column,
- each observation forms a row,
- each type of observational unit forms a table. 

Wickham’s paper is the main methodological starting point for the repository and motivates the data-cleaning choices used here.

## References
